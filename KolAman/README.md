







# מערכת ניהול וסריקת התרעות



 סימולטור  שמדמה קבלת אירועים בלי הפסקה מסווג אותם לפי איזורים מבצע ולידציה שומר לטבלת sql בשביל מקור מידע אמין  שמאפשר באמצעות שאילתות לבצע  קבלת  אינפורמציה  ונתונים זהו פרויקט שמקבל אירועים והתרעות באמצעות RabbitMQ, מבצע ולידציה וסיווג של המידע, שומר את הנתונים ב־ ומאפשר לבצע חיפוש וניתוח של התרעות באמצעות Elasticsearch. תוך כדי שליחת לוגים לאלסטיק  בשביל חיפוש מהיר לפי מילות מפתח

המטרה היא ליצור מערכת שמסוגלת לקבל התרעות, לעבד אותן, לשמור אותן בצורה מסודרת ולאפשר חיפוש וסריקה יעילים של המידע.


#  מבנה המערכת

המערכת מורכבת ממספר חלקים עיקריים:

- producer c sharp –  ושליחה לקפקא כצינור מידע קבלת הודעות ואירועים.
- Consumer python –   Uמבצע ולידציה וסיווג לפי איזור על פי נקודות ציון ומקבל את ההודעות.
- producer python – שולח את ההודעות המסווגות לרביט mq לארבעה תורים לפי פיקודים
- producer c sharp – מקבל את ההודעות מרביט מבצע ולידציות ושומר לmysql כמבנה נתונים רלציוני ןמקור אמת יחיד בהתחשב בזה שמבנה ההודעה אחיד בכולם
הוא כולל בעצם 3 שירותים שמירה לדאטה בייס עם הןספת שדה פיקוד סריקה כל הזמן של הדאטה בייס האם הגיעה הודעה חדשה  וטיפול בהודעה




- controller api  – חשיפת פעולות המערכת באמצעות API.
